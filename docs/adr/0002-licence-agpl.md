# 0002: Licence AGPL-3.0-only

**Status:** accepted · 25 Oct 2026

## Context

The hackathon requires a public repository with an open-source licence. The team plans to run sellix as a commercial hosted product afterwards.

## Decision

License the code under the GNU Affero General Public License v3.0 only (`AGPL-3.0-only`).

## Consequences

- It's an approved open-source licence, so it meets the hackathon rule.
- Anyone who runs a modified version as a network service must publish their changes under the same licence. That makes closed copycat hosted versions harder.
- The submitted code stays open source permanently.
- Several people contribute, so the team agrees in writing who owns the code. That keeps future options open, such as offering a commercial licence.
