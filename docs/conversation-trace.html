Sellix Conversation Trace

A customer orders two chocolate cookies, adds a brownie, places the order and pays. Below, every turn of that chat is drawn as the calls the backend makes, in order, and the rows it leaves in Postgres.

code calls code engine and model reads and writes Postgres Instagram or PayPal written by the model written by code a table

Companion to the Sellix Agent Harness page. Item ids, prices, order number and the model's wording are examples; the calls, their order, the routing, the confirmation check and the templates were checked against the code at commit c3b2994.
